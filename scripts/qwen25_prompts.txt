# Fixed prompt suite for Qwen2.5-0.5B-Instruct greedy parity.
#
# Blank lines and lines starting with '#' are ignored. Each remaining line is one user
# turn, wrapped in Qwen's instruct chat template unless --raw-prompt is passed.
#
# Prompts are open-ended on purpose: the parity suite must exercise at least 32 decode
# steps per prompt, and short factual questions make the model emit EOS well before that.
# They still span distinct behaviours (exposition, code, enumeration, arithmetic
# reasoning, translation) so a numerical fault is unlikely to hide behind one output style.

Explain what a compiler does and list its main stages.
Summarize the plot of Pride and Prejudice.
Explain the difference between a list and a tuple in Python.
Describe how photosynthesis works in plants.
Explain what an API is to someone new to programming.
